# telegram-temp-mail-bot

A powerful Telegram bot that creates temporary email addresses using the mail.tm API with inline buttons and force join channel feature.

---

## ✨ Features

- 🔒 **Force Join Channel** - Users must join your channel before using the bot
- 📧 **Create Temporary Email** - Generate disposable email addresses instantly
- 📬 **Check Inbox** - View all received messages with pagination
- 📖 **Read Messages** - Read full message content with HTML formatting
- 🔄 **Refresh Inbox** - Fetch new messages manually
- 🗑️ **Delete Messages** - Delete individual or all messages
- 📝 **New Email** - Create a new email address (old one is deleted)
- 🎨 **Colorful Inline Buttons** - Beautiful UI with emojis and colors
- 📊 **Unread Counter** - Shows number of unread messages
- 💾 **SQLite Database** - Persistent storage for all data
- 🌐 **Environment Variables** - Secure configuration management
- 📱 **HTML Formatting** - Rich text formatting for better user experience
- ⏰ **Auto-expiry** - Emails expire after 24 hours
